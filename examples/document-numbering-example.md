# Document Numbering Example

```text
Canonical objectUID:
DOC-01J9P7K2M4N6Q8R0S2T4U6V8W

Enterprise document number:
ABC-PRJ001-ENG-DRG-000245

Revision:
C02

Display title:
Equipment Layout

Filename:
ABC-PRJ001-ENG-DRG-000245_C02_Equipment-Layout.pdf
```

Only the canonical object UID is the primary EIOS identity. The enterprise document number is a stable business identifier and is never reused. The filename is a mutable display projection.
