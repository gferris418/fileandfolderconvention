# Template Catalogue

## Purpose

Templates are reusable human-facing navigation blueprints for the seven EIOS information scopes. They do not create canonical objects or relationships; they help users organize information consistently once the canonical business context already exists.

| Template | Purpose |
|---|---|
| `group/` | Provide a Group-level enterprise navigation structure across Governance, Operations, Finance/Treasury, Commercial, People, Knowledge, Shared Services, and Archive. |
| `entity/` | Provide a navigation structure for information whose strongest business context is one canonical legal/business Entity. |
| `opportunity/` | Provide a pre-award workspace from source RFP/RFQ through requirements, bid development, approval, submission, clarification, award transition, and closure. |
| `project/` | Provide an execution workspace separating project control, contract/commercial, engineering, procurement/logistics, site execution, QA/QC/HSE, finance, correspondence, training, and closeout. |
| `contract/` | Provide a contract-lifecycle workspace separating formation, signed agreement, amendments, obligations, payment, correspondence, claims/disputes, and closeout. |
| `function/` | Provide a function-level workspace for policies/procedures, operations, controls/compliance, reporting, reference knowledge, records support, and archive. |
| `external/` | Provide one neutral workspace/view for a third-party Organization across profile/due diligence, relationships, commercial, contracts, deliverables, correspondence, and compliance evidence. |

## Rule

A template may be extended only when every added structural node has an approved purpose, typical-content definition, and boundary/exclusion in accordance with `standard/v1.0/15-purpose-register.md` and `standard/v1.0/10-exceptions-and-governance.md`.
