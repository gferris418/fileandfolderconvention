# 07 — Governance Structure

Recommended structure:

```text
01_GOVERNANCE/
├── 01_STRATEGY/
├── 02_CORPORATE_SECRETARIAL/
├── 03_LEGAL/
├── 04_RISK_COMPLIANCE/
├── 05_POLICIES_PROCEDURES/
├── 06_INTERNAL_AUDIT/
└── 07_BOARD_MANAGEMENT/
```

Governance material often has heightened classification, retention, legal-hold, or access requirements. These requirements must be implemented through EIOS policy and provider-native controls; the folder hierarchy is only the navigational projection.

Policies and procedures should use controlled titles, effective dates, status, ownership, and supersession metadata rather than relying on file names such as `final` or `old`.
